# 老谢手工面 · 远程点单服务器包

Mac 做服务器主机，顾客手机和老板手机都连这台 Mac。

## 两套系统，入口分开
- 顾客点单：`/order.html` —— 只点菜、付款、我已付款、我已到店，里面没有任何后厨/后台入口。
- 老板后厨：`/kitchen.html` —— 老板手机接单、确认收款、开始做、出餐。
- 老板后台：`/admin.html` —— 老板手机改座位数、上传收款码、开关售罄。
- 订单存在 Mac 服务器的 `data/orders.json` 里，顾客手机和老板手机通过服务器同步，不是各存各的。

## 在 Mac 上启动
1. 把这个文件夹放到 Mac 上（从 GitHub 拉下来，或直接拷过去）。
2. 打开 Mac 终端，进到这个文件夹，运行：
   ```
   python3 server.py
   ```
   看到“服务器已启动，端口 8000”就行，Mac 不要关机、不要断网。
3. 同一个 Wi-Fi 下，手机浏览器打开：
   - 顾客：`http://<Mac的局域网地址>:8000/order.html`
   - 后厨：`http://<Mac的局域网地址>:8000/kitchen.html`
   - 后台：`http://<Mac的局域网地址>:8000/admin.html`
   Mac 的局域网地址在“系统设置 > 网络”里看。
4. 要在店外远程点单，需要像老爹面馆那样再接一个隧道（例如 cloudflared）把 8000 端口映射到公网，那一步不在这个包里自动做。

## 付款和配送
- 付款：顾客扫老板自己的支付宝/微信收款码付，点“我已付款”，老板在后厨确认收款后才做面，钱不走平台。
- 配送：外卖单填地址、电话、备注，后厨按单出餐；叫骑手、骑手定位不在这个包里，要另外接配送平台。
